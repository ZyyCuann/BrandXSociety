# BrandxSociety — Live Interactive Prototype & Redesign

Interactive 3-Panel UX Demo & Identity-Driven Creator Platform for **BrandxSociety**.

## ✨ Fitur Utama
- **3-Panel Interactive Shell**:
  - **Left**: Step-by-step Flow Navigator (People Demo & Brand Demo).
  - **Center**: Native-feel Smartphone Mockup dengan gestur swipe & haptic interactions.
  - **Right**: Step rationale, UX considerations & real-time System Event Trace.
- **Natural Swipe & Drag Gestures**:
  - Geser kiri/kanan pada layar handphone untuk berpindah antar step secara alami.
  - Drag vertikal untuk scrolling mulus tanpa scrollbar/scroll button bawaan browser.
- **100% Ikon Vektor Profesional**:
  - Nol emoji/emoticon teks.
  - Ikon khusus untuk setiap utilitas (Home, Feed/Radar, Identity/Badge, Rewards/Wallet, Profile/Avatar).
- **Interactive Mobile Features**:
  - Form & chip filters interaktif.
  - Modal bottom sheet penarikan dana (Payout).
  - Drawer notifikasi live.
  - Mockup TikTok player nyata untuk video submission.

## 🚀 Akses Langsung
Buka \index.html\ langsung di browser atau host melalui GitHub Pages.
